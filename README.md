# Умный сортировщик оборудования

Локальное Windows-приложение для сортировки фотографий навесного оборудования спецтехники по визуальным образцам.

## Возможности
- Рекурсивное сканирование папок с JPG/JPEG/PNG/WEBP.
- Категории и несколько фото-образцов для каждой категории.
- Универсальный поиск любого предмета по загруженному фото-образцу — категории не зашиты в алгоритм.
- Сравнение по CLIP-эмбеддингам с двумя представлениями кадра: стандартным и полным без обрезания краёв.
- При нескольких образцах категория оценивается по среднему двух лучших совпадений, чтобы уменьшить влияние случайного удачного образца.
- Результаты с оценкой сходства, категория «На проверку» и ручная коррекция.
- Копирование подтверждённых фотографий; исходники не удаляются и не перемещаются.
- Локальное хранение категорий, образцов и истории.
- Работа на CPU, рассчитана на обычный ПК с 8 ГБ RAM.

## Установка на Windows 10
1. Установите Python 3.10 x64 с python.org, отметьте **Add Python to PATH**.
2. Скачайте ZIP репозитория.
3. Запустите `install.bat`.
4. При первом запуске модель CLIP будет загружена в локальный кеш (нужен интернет). После этого распознавание работает локально.
5. Запустите `run.bat`.
6. Для проверки вспомогательной логики без запуска интерфейса выполните `test.bat`.

## Использование
1. Вкладка «Образцы»: выберите категорию и добавьте несколько фотографий, показывающих разные модели и ракурсы.
2. Выберите исходную папку и нажмите «Анализировать».
3. Просмотрите результаты, при необходимости измените категорию.
4. Выберите папку назначения и нажмите «Копировать подтверждённые».

**Важно:** число сходства — это оценка визуального сходства, а не гарантированная вероятность правильной классификации. Один образец может не покрывать все варианты изделия. Начинайте с нескольких образцов и проверяйте категорию «На проверку».

## EXE
После установки зависимостей запустите `build_exe.bat`. PyInstaller создаст папку `dist\SmartEquipmentSorter`. Веса нейросети не включаются в EXE автоматически: их нужно заранее скачать запуском приложения, затем переносить кеш модели отдельно.

## Ограничения первой версии
Это первая рабочая основа приложения. Качество распознавания зависит от образцов и выбранного порога. Порог сходства и минимальная разница между двумя лучшими категориями — предварительные настройки, не откалиброванные на вашем наборе фотографий. Для надёжной работы добавляйте несколько разнообразных образцов на категорию и проверяйте спорные результаты. Встроенные автоматические тесты проверяют ранжирование, неоднозначность и исключение папок, но не заменяют проверку на реальных фотографиях.
